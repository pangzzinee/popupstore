# 🎪 팝업 캘린더

캐릭터 IP와 브랜드가 함께 만든 **팝업스토어·콜라보 일정**을 한곳에 모은 정적 웹사이트입니다.

민음사 × 오늘의귀여움처럼 출판사가 캐릭터와 책을 만들고, 엔제리너스 × 빵고미처럼
카페가 캐릭터 빵을 파는 — 그런 협업들을 기록합니다.

## 기능

- **진행 중 / 오픈 예정 / 종료** 상태 자동 계산 (오늘 날짜 기준, D-day 표시)
- **캘린더 보기** — 월별 그리드에서 어느 날 어떤 팝업이 열려 있는지 확인
- **목록 보기** — 임박한 순 / 최근 시작한 순 / 이름순 정렬
- 업종(출판·카페·뷰티·편의점·스포츠 등)과 키워드 검색 필터
- 항목별 상세 정보 + 출처 링크
- 다크 모드, 모바일 대응

## 구조

```
index.html            페이지 골격
assets/css/style.css  스타일
assets/js/app.js      필터·캘린더·상세 로직 (의존성 없음)
data/popups.json      ← 데이터는 전부 여기
data/README.md        항목 추가 방법
```

의존성도 빌드 도구도 없습니다. `data/popups.json`에 항목을 추가하면 끝입니다.

## 로컬에서 보기

`fetch()`로 JSON을 읽기 때문에 파일을 그냥 더블클릭하면 동작하지 않습니다. 정적 서버로 여세요.

```bash
npx serve .
# 또는
python3 -m http.server 8000
```

## 배포

`main` 브랜치에 푸시하면 GitHub Actions가 GitHub Pages로 자동 배포합니다.
(저장소 Settings → Pages → Source를 **GitHub Actions**로 설정해 두세요.)

## 데이터에 대하여

운영 기간·시간은 주최 측 사정으로 바뀔 수 있습니다. 방문 전 공식 채널에서 반드시 확인하세요.
각 항목에는 확인에 사용한 기사·공지 링크를 `sources`로 함께 담았습니다.
