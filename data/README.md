# 데이터 추가하는 법

모든 정보는 `data/popups.json` 한 파일에 들어 있습니다.
`popups` 배열에 항목 하나를 추가하면 사이트에 바로 반영됩니다. (빌드 과정 없음)

## 항목 템플릿

```jsonc
{
  "id": "brand-ip-2026",          // 겹치지 않는 고유 키 (영문·숫자·하이픈)
  "title": "팝업 이름",
  "ip": ["캐릭터 이름"],           // 여러 개면 배열에 나열
  "brand": "협업 브랜드",
  "category": "cafe",             // 아래 '업종 코드' 참고
  "type": "팝업스토어",            // 팝업스토어 / 상품 콜라보 / 전시 / 체험 공간
  "country": "KR",                // 팝업이 열리는 나라
  "ipOrigin": "JP",               // 캐릭터의 국적: KR/JP/US/FI/NL/MIX
  "region": "서울 송파",
  "areas": ["잠실·송파"],          // 지역 필터에 쓰이는 동네 태그 (아래 참고)
  "venue": "정확한 장소",
  "startDate": "2026-09-01",      // YYYY-MM-DD, 모르면 null
  "endDate": "2026-09-16",        // YYYY-MM-DD, 모르면 null
  "openEnded": false,             // 시작했는데 종료일이 공개 안 됐으면 true
  "periodText": "",               // 기간을 특별하게 적고 싶을 때만 (선택)
  "hours": "10:30 ~ 21:30",
  "reservation": "현장 방문",      // 현장 방문 / 사전 예약 / 회차 예약 / 매장 구매
  "brandDomain": "emart24.co.kr", // 협업 브랜드 공식 도메인 (로고 표시용, 선택)
  "image": "",                    // 사진 주소 (비워두면 자동 생성 썸네일)
  "imageCredit": "",              // 사진 출처 표기 (선택)
  "summary": "한두 문장 설명",
  "highlights": ["굿즈나 메뉴 등 볼거리"],
  "note": "확인이 필요한 부분",     // 선택
  "coords": {                     // 지도·거리 계산용 (선택, 전국 단위면 생략)
    "lat": 37.5093, "lng": 127.1020, "name": "엔제리너스 석촌호수 DI점"
  },
  "official": {                   // 상세 화면 상단의 공식 페이지 버튼
    "label": "공식 인스타그램 (포스터·사진)",
    "url": "https://www.instagram.com/..."
  },
  "sources": [
    { "title": "출처 제목", "url": "https://..." }
  ]
}
```

## 업종 코드

| 코드 | 라벨 |
|---|---|
| `publish` | 📚 출판·문구 |
| `food` | 🍰 식음료 |
| `cafe` | 🥐 카페·베이커리 |
| `cvs` | 🏪 편의점·유통 |
| `beauty` | 💄 뷰티 |
| `fashion` | 👜 패션·잡화 |
| `sports` | ⚽ 스포츠 |
| `culture` | 🎪 전시·엔터 |

업종을 새로 만들려면 `categories` 배열에 `{ "id", "label", "emoji" }`를 추가하세요.

## 지역 태그 (`areas`)

지역 필터 칩에 쓰입니다. `data/popups.json`의 최상위 `areas` 배열이 칩 순서를 정하고,
각 항목의 `areas`에 적힌 값과 대조합니다. 현재 값:

`성수` · `여의도` · `용산` · `강남` · `홍대` · `잠실·송파` · `영등포` · `부산` · `청주` · `전국·온라인`

- 한 팝업이 두 곳에서 열리면 배열에 둘 다 넣으세요. (예: `["성수", "강남"]`)
- 온라인 판매나 전국 매장 상품이면 `["전국·온라인"]`
- 새 동네를 추가하려면 최상위 `areas` 배열에도 같은 글자를 넣어야 칩이 생깁니다.

## 기간이 애매할 때

| 상황 | 어떻게 적나 | 화면에 보이는 모습 |
|---|---|---|
| 시작·종료 둘 다 앎 | `startDate` + `endDate` | `2026.09.01(화) ~ 2026.09.16(수)` |
| 시작했는데 종료일 미공개 | `startDate` + `endDate: null` + `openEnded: true` | `2026.08.31(일) ~ 종료일 미정` · 상태는 **진행 중** |
| 하루짜리 출시 | `startDate` + `endDate: null` | `2026.05.02(토) 출시` |
| 아무것도 모름 | 둘 다 `null` | `기간 미정 · 상시` (캘린더에는 안 뜸) |
| 문장으로 적고 싶을 때 | `periodText` | 적은 그대로 표시 (상태 계산은 날짜 기준 그대로) |

## 썸네일 이미지

카드마다 위쪽에 보이는 색 띠입니다. **비워두면 자동으로 만들어집니다.**
캐릭터 이름을 해시해서 12가지 색 중 하나와 3가지 배경 무늬 중 하나를 고르기 때문에,
같은 IP는 언제나 같은 모양이 나오고 다른 IP끼리는 잘 구분됩니다. 손댈 필요 없습니다.

진짜 사진을 넣고 싶으면 `image`에 주소를 적으세요.

```jsonc
"image": "https://example.com/photo.jpg",
"imageCredit": "직접 촬영"
```

사진이 깨지거나 불러와지지 않으면 자동 생성 썸네일이 그대로 보이므로,
링크가 죽어도 화면이 망가지지 않습니다.

> ⚠️ **저작권 주의.** 캐릭터 굿즈 사진과 언론사 사진은 대부분 저작권이 있습니다.
> 공개된 사이트이므로 남의 사진을 링크로 끌어다 쓰지 마세요. 직접 찍은 사진,
> 또는 사용 허락을 받은 사진만 넣고 `imageCredit`에 출처를 밝히는 것을 권합니다.
> 많은 언론사·브랜드 사이트는 외부 링크를 막아놔서 어차피 깨져 보이기도 합니다.

## 브랜드 표식 (`brandDomain`)

브랜드 이름 앞에 붙는 작은 사각 칩입니다. **두 겹으로 되어 있습니다.**

1. **머리글자 칩** — 브랜드 이름에서 첫 글자를 뽑아 항상 표시합니다.
   (민음사→`민`, CASETiFY→`CA`, KBO 리그 구단→`KBO`)
   브랜드 이름별로 색이 자동으로 정해지고, **네트워크를 전혀 쓰지 않아 언제나 보입니다.**
2. **공식 파비콘** — `brandDomain`을 적으면 그 위에 덮어씌웁니다.

```jsonc
"brandDomain": "kleague.com"
```

파비콘은 Google → DuckDuckGo 순으로 시도하고, 둘 다 실패하면 머리글자 칩이 그대로
남습니다. 광고 차단기나 회사 네트워크가 파비콘 서비스를 막아도 화면이 비지 않습니다.

- **파비콘이 그 브랜드 자신일 때만 적으세요.** 엔제리너스는 공식 사이트가 롯데GRS
  아래에 있어 롯데 로고가 뜨므로 비워뒀습니다. CU(→BGF리테일)도 마찬가지입니다.
- 로고를 식별 목적으로 그대로 쓰는 건 일반적으로 허용되는 범위(지명적 사용)지만,
  로고를 변형하거나 제휴·후원 관계가 있는 것처럼 보이게 쓰면 안 됩니다.

## 규칙

- **날짜를 모르면 지어내지 말고 `null`로 두세요.** `null`이면 '기간 미정'으로 분류되고
  캘린더에는 표시되지 않지만 목록에서는 검색됩니다.
- `sources`에는 실제로 확인한 기사·공식 공지 링크를 넣습니다.
- 진행 상태(진행 중 / 오픈 예정 / 종료)는 오늘 날짜를 기준으로 **자동 계산**되므로
  직접 적을 필요가 없습니다.
- 수정 후 `meta.updatedAt`을 오늘 날짜로 바꿔주세요.
